    Game Rules

    Goal
    Reach the final scene and roll 20+ on a d20 to defeat the boss.

    Gameplay
    All players control one shared character. Each scene, one player decides which of 3 choices to make. Use {field_key} placeholders to weave character details into the text.

    Choice Outcomes
    Damage — Lose 1 HP (0 HP = defeat)
    Item — Gain an item (+1 to final roll)
    Level Up — Gain a level (+1 roll attempt)

    Starting Stats
    HP is configurable in story settings (default 3). Players start at Level 1 with 0 Items.

    Conditional Text
    Add text that only appears based on HP, items, level, or previous scene outcomes.

    Final Boss
    Players roll a d20, add item count as bonus. Level = number of roll attempts. Need 20+ total to win.
