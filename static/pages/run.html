Game Rules

Goal
Reach the final scene and roll 20+ on a d20 to defeat the boss.

Gameplay
Read scenes aloud. All players control one shared character. Each scene, one player decides which of 3 choices to make. Let them discuss first.

Choice Outcomes
Damage — Lose 1 HP (0 HP = defeat)
Item — Gain an item (+1 to final roll)
Level Up — Gain a level (+1 roll attempt)

Starting Stats
3 HP (configurable), Level 1, 0 Items

Final Boss
Have players roll a d20, add item count as bonus. Level = number of roll attempts. Need 20+ total to win.
